The project went through three generations:
1. **Melody**: the old Electron/React app.
2. **Phono**: an empty Qt/QML mockup, also called the "Spotify-inspired desktop player".
3. **Monolist Player**: Phono plus Melody's engine in C++ (libmpv, yt-dlp, SQLite).

Decisions as of 2026-09-22: **Evolve Phono** (flat, Archivo, signal red #ec3013, 2px rules, zero radius, B&W photos), **desktop first** (Windows/macOS/Linux; mobile later from the same Qt code), and the unpacked yt-dlp build.
